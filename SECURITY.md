# Security policy

Current only reads public Stellar ledger data. It does not request or store secret keys, sign transactions, or submit payments.

## Reporting a vulnerability

Do not publish credentials, personal information, or an exploitable vulnerability in a public issue. The repository does not yet have a verified private reporting contact or published security response window. Before the project is opened for outside contributions, its owner should enable GitHub private vulnerability reporting or publish a maintainer-controlled security contact here.

## Security scope

Please report issues involving unsafe handling of public ledger data, cross-site scripting, unsafe CSV generation, unexpected network requests, or privacy claims that do not match application behavior. Reports about Horizon availability or third-party explorer uptime should identify the external service involved.

The application has not undergone a security audit. Do not use it as a custody tool or as the sole source of financial records.
